# DREAMWALKER — Uyku · güncellemeler

Bu depo yalnızca oyunun **oyun içi güncelleme** dosyalarını barındırır; kaynak kod içermez.

- `latest.json`: en son sürüm, paket adresi, SHA-256 ve kısa notlar. Oyun açılışta buna bakar.
- **Releases**: her sürümün oyun paketi (`Dreamwalker.pck`).

Oyunu güncellemek için bir şey yapmana gerek yok: ana menüde "Yeni sürüm" kartı çıkınca **Güncelle**'ye bas.

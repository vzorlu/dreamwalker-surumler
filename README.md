# Dreamwalker eski dağıtımı

Eski oyunda bu geçiş güncellemesini indirip yeniden başlatın. Kurucu en güncel Windows paketini indirir, doğrular ve aynı oyun klasörüne kurar. Eski Dreamwalker dosyaları kaldırılır ve yeni oyun otomatik açılır. Kayıtlarınız ve özel haritalarınız korunur.

**[Güncel Windows sürümü](https://github.com/Thamassa/letters-to-the-sleeper-releases/releases/latest)** · [Yeni EXE'yi doğrudan indir](https://github.com/Thamassa/letters-to-the-sleeper-releases/releases/latest/download/LettersToTheSleeper.exe)

Bu depodaki `Dreamwalker.pck`, eski oyunun güncelleyicisi içindir. Tek başına çalıştırılmaz.

---

Download this migration update in the old game and restart. The installer downloads and verifies the latest Windows package, installs it in the same folder, removes obsolete Dreamwalker files and launches the new game. Saves and custom maps are preserved.
